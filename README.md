# CampusDesk

An AI document assistant. Upload your own documents (like a college handbook) and ask questions. It answers using only those documents and shows the source passage it used.

## What problem does it solve?
Students and staff waste time searching through long PDFs like handbooks and policy documents just to find one simple answer. CampusDesk lets them ask a question in plain language and get a direct answer, along with the exact passage from the document it came from.

## Tech stack
Python, FastAPI, React, vanilla JavaScript widget, ChromaDB, SQLite, Gemini, Figma

## Planned features
- Upload PDF and DOCX documents
- Ask questions and get streamed answers with source citations
- Conversation history
- Embeddable chat widget for any website
